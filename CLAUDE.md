# Virtual Bench
This is a repo for benchmarking the performance of different Virtual Machine softwares, given the same physical resources and the same OS.

# Python environment
Use `uv` to manage the Python environment. Run Python via `uv run` (e.g. `uv run python analyze/analyze.py results`) and manage dependencies with `uv add` / `uv sync`. Do not invoke a bare `python`/`pip` or a manually-created venv.
